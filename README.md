# Прототип сервиса судебных заседаний

Кликабельная итерация v4 для сервиса очного/удаленного проведения судебного заседания.

## Состав

- `index.html` - рабочий прототип интерфейса.
- `styles.css` - визуальная стилистика в духе Единой платформы цифрового правосудия.
- `script.js` - интерактивные сценарии: drawer-карточки, блокировка завершения, режимы видео, triage заявок.

## Локальный запуск

Откройте `index.html` в браузере или запустите статический сервер из этой папки.
